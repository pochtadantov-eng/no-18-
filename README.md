# Олег Лямкин — бот-охранник для Telegram-чатов

- **Медиа-фильтр**: фото, видео (по превью), GIF, кружки, стикеры, картинки-файлы проверяются через Claude vision.
  18+ / расчленёнка / жестокость → сообщение удаляется, пользователь банится (теряет все права и удаляется из группы).
- **Антиспам**: N сообщений/стикеров/чего угодно подряд за T секунд → весь всплеск удаляется, нарушитель получает мут (или бан).
- **Настройка** — в личке с ботом (`/start`): выбираете чат, включаете/выключаете фильтры, порог спама и наказание. Доступно только владельцу.
- Админы чата не проверяются.

## Запуск
1. Создайте бота у @BotFather, **отключите Group Privacy** (`/setprivacy` → Disable), чтобы он видел все сообщения.
2. `cp .env.example .env` и заполните `BOT_TOKEN`, `OWNER_ID`, `ANTHROPIC_API_KEY`.
3. `pip install -r requirements.txt && python main.py`
4. Добавьте бота в группу админом (права: удалять сообщения, блокировать пользователей), затем в личке `/start` → выберите чат → включите защиту.

Ограничение: видео проверяется по превью-кадру, анимированные стикеры (.tgs) — по превью, если оно есть.
