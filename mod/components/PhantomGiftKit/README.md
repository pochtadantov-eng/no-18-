# PhantomGiftKit

Локальные подарки, визуальные балансы и casino bridge. Пустой пакет в этапе 0.

Копируется в `TMessagesProj/src/main/java/org/telegram/pampgram/gifts/`.
Пакет на Android: `org.telegram.pampgram.gifts`.

Casino bridge включается только когда в репозиторных секретах заданы
`CASINO_BRIDGE_URL` и `CASINO_BRIDGE_TOKEN`; значения подставляются workflow'ом
в билдовую копию и не попадают в git.
